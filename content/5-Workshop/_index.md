# Workshop: Building an End-to-End ML System on AWS

In this section, we will go through each step of building a complete Machine Learning system on AWS, from data processing, model training, API deployment, to monitoring and pipeline automation.

|---------|---------|

| 5.2 Prerequisites | AWS account, IAM, tools |
| 5.3 Setup | IAM, S3, SageMaker Studio, config.py |
| 5.4 Data Processing | Load, process, and upload data |
| 5.5 Training | XGBoost baseline + HPO |
| 5.6 Model Registry | Version management via JSON |
| 5.7 Deployment | Endpoint + Lambda + API Gateway |
| 5.8 Monitoring | CloudWatch Alarms + Model Monitor |
| 5.9 Pipeline | End-to-end automation |
| 5.10 Cleanup | Delete resources to avoid costs |
